# Вкладка Media

Полноценный плеер в главном меню: обложка, волна спектра, перемотка,
кнопки, текст песни. Открывается кликом по волне в панели
(`KeystoneBridge.mediaRequested`) и `ipc call keystone media`.

- **Обёртка:** `MediaHubTab.qml`, размер 760×480. Контракт описан в `../Hub/README.md`.
- **Содержимое:** `Media.qml`, `required property var player` (берётся из `hub.player`).
- **Службы:**
  - MPRIS через `MediaManager`: одна общая отметка позиции раз в 250 мс;
  - `MediaPalette`: цвета из обложки;
  - `AudioSpectrum`: спектр. Захватывается, только пока вкладка видна и есть плеер (`AudioSpectrum.acquire/release`).
- **Стоимость:** создаётся при первом открытии, затем остаётся в памяти. Если вкладку выключить, она уничтожается.
- **Частая ошибка:** `player` объявлен как `required`, без него компонент не создастся. Обёртка всегда передаёт его, пусть даже `null`.
