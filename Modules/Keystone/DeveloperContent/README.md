# Вкладка Developer

Список контейнеров Docker: группы compose, запуск, остановка, перезапуск, удаление.

- **Обёртка:** `DeveloperHubTab.qml`, размер 760×480. Контракт описан в `../Hub/README.md`.
- **Опрос:** `DockerWidget.qml` спрашивает docker раз в 4 с, только пока виден он сам и его родитель (`polling: parent.visible && root.visible`). Поэтому `DockerWidget` должен оставаться прямым потомком обёртки.
- **Стоимость:** пока вкладка закрыта, опроса нет. Выключенная вкладка не создаётся вовсе.
