# Раскладка клавиатуры на панели

Флаг текущей раскладки: 🇷🇺 при русской, 🇺🇸 при английской. Клик переключает
на следующую раскладку, подсказка показывает её название.

- Включается в Настройках → Общие → Панель, компонент «Раскладка клавиатуры»
  (id `keyboardLayout` в `PersonalizationConfig.barComponentIds`).
- Раскладку берёт из niri: `Niri.currentKeyboardLayoutName`, переключение —
  `Niri.cycleKeyboardLayout()` (плагин `Clavis.Niri`, `core/plugin/niri`). Своих
  таймеров и опросов нет: niri сам сообщает о смене раскладки.

## Файлы

| Файл | Что делает |
|---|---|
| `KeyboardLayout.qml` | Пилюля на панели: флаг, клик, подсказка. |
| `LayoutFlag.qml` | Рисует флаг прямоугольниками (не эмодзи: им нужен цветной шрифт). Есть ru, us, ua, de, fr; для остальных — две буквы кода. |
| `KeyboardLayoutCodes.js` | Имя раскладки из niri («English (US)», «Russian») → код флага. |

## Как добавить язык

1. В `KeyboardLayoutCodes.js` — строку в `known`: регулярное выражение по
   имени из `niri msg keyboard-layouts` и двухбуквенный код.
2. Если флаг полосатый — запись в `stripes` в `LayoutFlag.qml` (цвета сверху
   вниз или слева направо). Иначе будет плашка с буквами кода.
