# Bug 1. Пропавшие иконки после урезания Material Symbols

## 1. Причина бага

Скрипт `scripts/subset-icon-font.sh` сверял имена иконок из кода с **именами
глифов** в шрифте. Это неверно: Qt подставляет иконку, прогоняя строку через
таблицу лигатур GSUB (`rlig`), и у части иконок имя строки **не совпадает** с
именем глифа.

| В коде | Глиф в шрифте |
|---|---|
| `smartphone` | `mobile` |
| `draft` | `note` |
| `restore` | `history` |
| `clear` | `close` |
| `mode_night` | `brightness_2` |
| `battery_android_5` | `battery_android_digit_five` |

Такие имена отбрасывались как «несуществующие», хотя иконка есть в шрифте.
Отсюда 173 пропавшие иконки.

Сопутствующие причины:

- Подстановки лежат в extension-обёртке (`type 7`). Без её разворота таблица
  GSUB выглядела пустой, и карта лигатур не строилась.
- Имена собирались только из `.qml` и `.js`. Погодные иконки `sunny`, `rainy`,
  `foggy`, `weather_snowy`, `thunderstorm` задаются в C++
  (`core/src/weather_calculator.cpp`) и в обзор не попадали.
- Имена из комментариев тоже попадали в шрифт (52 лишних глифа).
- `assert 'rclt' in features` был ложной проверкой: в этом шрифте `rclt` —
  пустой тег (0 подстановок), и pyftsubset не переносит его в лёгкий
  результат. Прогон проходил только за счёт лишних глифов.

## 2. Решение

Карта «строка → глиф» строится из самой таблицы GSUB шрифта, а не из имён
глифов:

- Разворот extension-обёрток (`ExtSubTable`) при разборе GSUB.
- Цифры и `_` в именах раскодируются через cmap (`digit_one`, `underscore`),
  с предпочтением строчных букв: шрифт отображает `a` и `A` в один глиф.
- Обзор расширен на `.cpp`, `.cc`, `.h`, `.hh` и `.json`.
- Комментарии (`//`, `/* */`) вырезаются до поиска имён.
- Динамические имена разворачиваются по началу: `"battery_android_" +` → все
  подходящие строки.
- Контекст (`iconName:`) больше не нужен: совпадение со строкой лигатуры само
  отсеивает `label`, `route`, `policy` — это убрало ~480 лишних глифов от
  широких префиксов.
- Проверка заменена на строгую: наличие и непустота `rlig`; каждое ожидаемое
  имя должно разрешаться в живой глиф уже в готовом файле.
- Добавлена диагностика: опечатки в `iconName:` и случаи `строка ≠ глиф`.

## 3. Краткая информация (сделано)

**Сделано.** Логика извлечения переписана, скрипт обновлён, шрифт пересобран и
установлен.

| Вариант | Размер | Глифов |
|---|---|---|
| Полный | 13.60 МБ | 6182 |
| Было | 1.52 МБ | 764 |
| **Стало** | **0.94 МБ** | 493 |

- Размер меньше прежнего на **38%**, при этом 173 иконки вернулись.
- Проверка сборки: `558 из 558` имён разрешается, все оси на месте
  (`FILL`, `GRAD`, `opsz`, `wght`).
- Изменённый файл: `scripts/subset-icon-font.sh`.
- В git ничего не коммитилось и не пушилось.

**Требуется.** Перезапуск оболочки, старая версия шрифта ещё в памяти:

```bash
systemctl --user restart my-shell.service
```

**Замечание.** Ложные срабатывания вида `"2d"` (canvas context) и `"360"`
(id поиска) дают ~18 лишних глифов — доли килобайта, отсеивать не стали.
